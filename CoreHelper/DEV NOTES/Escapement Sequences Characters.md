| Échappement  | Caractère représenté | Description                                   |
| ------------ | -------------------- | --------------------------------------------- |
| `\'`         | `'`                  | Guillemets simples (apostrophe)               |
| `\"`         | `"`                  | Guillemets doubles                            |
| `\\`         | `\`                  | Antislash (backslash)                         |
| `\0`         | NUL                  | Caractère nul (valeur zéro)                   |
| `\a`         | (BEL)                | Avertisseur sonore (beep)                     |
| `\b`         | (BS)                 | Backspace (retour arrière)                    |
| `\f`         | (FF)                 | Saut de page (form feed)                      |
| `\n`         | (LF)                 | Line Feed → saut de ligne                     |
| `\r`         | (CR)                 | Carriage Return → retour au début de ligne    |
| `\t`         | (TAB)                | Tabulation horizontale                        |
| `\v`         | (VT)                 | Tabulation verticale                          |
| `\uXXXX`     | caractère Unicode    | Code Unicode 16 bits (ex : `\u00F8` = `ø`)    |
| `\UXXXXXXXX` | caractère Unicode    | Code Unicode 32 bits (ex : `\U0001F600` = 😀) |
| `\xNN`       | caractère Unicode    | Code en hexadécimal (longueur variable)       |
